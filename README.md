## ✨ Features

- ✅ **Add Task** — Easily input and add tasks  
- ✏️ **Edit Task** — Modify your task details  
- 🗑️ **Delete Task** — Remove a task if it’s no longer needed  
- 📌 **Task Status Filter** — Filter by All / Active / Completed  
- 📜 **History Section** — View a list of completed tasks  
- ⏰ **Timestamps** — Tasks are stored with their respective creation dates and times  

---

## 🛠️ Tech Stack

- **Frontend**: React.js, HTML5, CSS3, JavaScript
